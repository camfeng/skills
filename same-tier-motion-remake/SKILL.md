# 同档动效复刻

目标：只换口径信息，做到与参考片同档的排版、运动、材质与切镜。可交只来自目视对帧，不来自脚本绿灯。团队总决议与素材库选用，见 「内容部动效库决议」。

## 1. 先对帧，写合同，再改代码

对每一段参考片与当前成片，在固定时间网格上抽对照帧：`0.12 / 0.40 / 0.80 / 1.20 / 2.00 / 2.60 / 3.15 / 3.60`（按段长取），外加该段所有中后段切镜点。

每段合同必须写清：这一帧该有什么、在哪、什么密度与材质，以及禁止事项（发明 UI、改拓扑、晚拍早到、用示意图冒充）。禁止靠上一版拒词或记忆开剪。

## 2. 验收天花板与地板

- **地板（必要）**：结构层级、运动生命周期（入场+出场、前后半段、文字不裁切）、手法配方（视觉族 ≠ 通道标签）、对抗 QC、占用/拓扑/晚拍脚本。红了不许交。
- **天花板（充分）**：对着 contact sheet 目视。脚本绿了仍要看。只有目视通过后才能写「可交」并拷桌面。发现可修问题必须补完再拷，禁止带着缺口送审。

禁止把「有东西出现」「质量过线」「有第二拍」当成与原片同帧。

## 3. 材质与诚实缺口

可绘制的立体物、厚卡、密界面、拼贴屏、海报插画，都必须按原片材质语言重画，只换口径；禁止贴原片截图，也禁止标成诚实缺口。诚实缺口只留给真正不可得的资产（例如精确苹方），并在交付时披露近似替代。

文案长短可以阻止像素级对齐，但字体、色票、阴影、spring、布局拓扑与运动时钟必须从画面里量出来并一次做完。禁止改版式、发明界面、多写一行说明。

## 4. 反馈怎么接

点到的一个样本，要升成一类问题：写进合同与门禁，整卷重验。未提及的段落不得视为已审过。禁止只改被点名的几秒。

## 5. 横屏先过关，再做竖屏

竖屏不是把 16:9 裁成 9:16。横屏目视通过后才开竖屏。开剪前先写 9:16 空间布局板：每层在安全区内的落点。运动配方与帧时钟跟已过关横屏一致，只重新排空间。

默认画幅 `1080×1920`、30fps，段序与时长不变。文字必须大到手机可读。主视觉、字幕与水印避开抖音顶栏、右侧互动键、底部文案条。一次到位：布局板 → 实现全段 → 目视对帧 → 可修问题全部修完 → 再拷桌面新目录，禁止覆盖已过关的横屏目录。

## 6. 口径常量（若适配到本账号复刻）

- 水印：「Cam的AI内容部」
- 粉丝只说 200+；互动只说 差不多五千 / 接近五千
- 不要在英雄标题下叠多一行数字说明
- 不要把参考片里的原始物料贴进成片

## 7. 拆完必须回填素材库

过关后，把新抽出的手法、布局规矩和验收标准写回 `/workspace/research/remotion/cam-motion-lib/`（`TECHNIQUES.md`、`SELECT.md`、可引用组件），不要只留在这一次工程里。
